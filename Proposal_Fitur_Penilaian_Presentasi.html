1. Deskripsi Fitur

Proposal ini diajukan untuk menambahkan modul Sistem Tiketing & Gate Check-In Penonton pada platform 55th PIT IAGI & GEOSEA XIX 2026. Alur pendaftaran disederhanakan menggunakan metode Upload Bukti Transfer Mandiri (manual verification oleh admin). Dilengkapi opsi fleksibel **Pengaturan Nomor Kursi (Seat Assignment)** yang bisa diaktifkan atau dinonaktifkan oleh Admin melalui panel pengaturan.

2. Ruang Lingkup Pekerjaan & Detail Modul

Modul Sistem Deskripsi Kebutuhan Teknis
Halaman Registrasi Penonton Penyediaan form registrasi penonton (diakses langsung via Landing Page) untuk mengisi identitas dasar tanpa mewajibkan proses submit makalah ilmiah.
Modul Upload Bukti Transfer Peserta penonton dapat melihat instruksi nomor rekening bank panitia dan mengunggah (upload) bukti transfer pembayaran tiket langsung di dashboard.

E-Tiket & Generator QR Code Pembuatan kode tiket acak terenkripsi dan QR Code unik setelah disetujui. Informasi nomor kursi otomatis dicantumkan di E-Tiket (jika opsi nomor bangku diaktifkan).
Mobile Web Scanner Gate Pengembangan halaman scanner berbasis web khusus panitia (check-in gate) dengan validasi instan, status kehadiran, alert audio, dan perlindungan tiket duplikat.

4. Spesifikasi Teknis (Product Requirement Document)

4.1 Alur Pengguna (User Flow)

  • Pendaftaran: Penonton mengakses halaman pendaftaran khusus melalui tombol CTA di Landing Page, melengkapi form identitas, dan diarahkan ke instruksi pembayaran bank transfer panitia.
  • Pemberian Kursi otomatis: Saat Admin menekan tombol "Approve" bukti pembayaran, sistem akan mengecek status konfigurasi nomor kursi. Jika aktif (ON), sistem mengalokasikan nomor bangku unik berurutan (misal: S-001, S-002, dst.). Jika nonaktif (OFF), status akan diatur menjadi "Free Seating".
  • Check-in Lokasi: Saat barcode e-tiket dipindai oleh kamera HP panitia di gerbang masuk, layar scanner akan memvalidasi status lunas, mencatat waktu masuk, dan memunculkan nomor kursi peserta di layar HP panitia untuk memandu penonton.

4.2 Kebutuhan Fungsional (Functional Requirements)

  • FR-01 (Registrasi): Pembuatan endpoint `/tiket` mandiri yang aman dan ramah seluler (mobile-friendly).
  • FR-02 (Verifikasi Admin): Dashboard admin untuk menyetujui (Approve) atau menolak (Reject) bukti bayar dengan kolom input alasan penolakan.
  • FR-03 (Toggle Kursi): Opsi di halaman pengaturan admin untuk menyalakan/mematikan penomoran kursi penonton.
  • FR-04 (Web Scanner): Kamera web asinkron dengan feedback audio (beep berhasil, buzz eror) dan visual (layar hijau untuk sukses, merah untuk eror).

4.3 Rancangan Skema Database

Rancangan tabel database `tickets` yang akan diimplementasikan:

CREATE TABLE tickets (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    user_id BIGINT UNSIGNED NOT NULL,         -- Relasi ke users (pembeli)
    payment_id BIGINT UNSIGNED NULL,          -- Relasi ke tabel bukti bayar
    ticket_code VARCHAR(100) UNIQUE NOT NULL, -- Kode tiket (e.g. PIT-2026-V001)
    ticket_category VARCHAR(50) NOT NULL,     -- Mahasiswa, Anggota IAGI, Umum
    seat_number VARCHAR(20) NULL,             -- Nomor kursi (null jika Free Seating)
    price DECIMAL(12, 2) NOT NULL,            -- Nominal harga tiket
    status VARCHAR(20) DEFAULT 'pending',     -- pending, active, rejected
    checked_in BOOLEAN DEFAULT FALSE,         -- Status absensi masuk gate
    checked_in_at TIMESTAMP NULL,             -- Waktu scan check-in
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (payment_id) REFERENCES payments(id) ON DELETE SET NULL
);

4.4 Kebutuhan Non-Fungsional (Non-Functional Requirements)

  • Performa Kecepatan Validasi: Latensi verifikasi scan barcode di gerbang masuk ditekan di bawah **1 detik** per peserta.
  • Kompatibilitas HP: Web scanner dirancang responsif dan kompatibel dengan browser seluler (Chrome di Android, Safari di iOS).
  • Anti-Duplikasi: Perlindungan sistem agar barcode yang sama tidak bisa di-scan lebih dari satu kali (menghindari sharing e-ticket).
