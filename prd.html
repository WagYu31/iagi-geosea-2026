1. DESKRIPSI FITUR & STANDAR DESAIN (TASTE-SKILL)

Proposal ini diajukan untuk melengkapi modul Sistem Tiketing Penonton (Kategori Visitor Exclusive & Non-Exclusive), Standar Desain Premium Taste-Skill (Monokromatik Aksen & Aset 3D Profesional), Auto-Compress Bukti Transfer Client-Side & Camera Access, Registrasi Onsite oleh Admin, Multi-Payment, Gate Check-In QR Code Scanner, serta Modul Cetak Fisik Kartu Lanyard/ID Card Terpisah pada platform 55th PIT IAGI & GEOSEA XIX 2026.

  • Dua Skema Kategori Pengunjung (Visitor Exclusive vs Non-Exclusive):
    • Visitor Exclusive (Berbayar / Paid): Pengunjung yang memilih paket Exclusive wajib menyelesaikan pembayaran tiket (via QRIS, Transfer Luar Negeri, atau Tunai Onsite). Setelah diverifikasi, sistem menerbitkan E-Tiket berisikan QR Code Unik. Saat check-in di pintu masuk (gate), pemindaian QR Code memicu pencetakan Kartu Lanyard Khusus Exclusive (sebagai penanda akses area VIP/Exclusive).
    • Visitor Non-Exclusive (Gratis / Non-Berbayar / Free Pass): Pengunjung umum dapat mendaftar tanpa biaya (Rp 0) dan langsung mendapatkan E-Tiket berisikan QR Code Unik. Saat tiba di lokasi acara dan melakukan scan di pintu masuk (gate), sistem memvalidasi kehadiran dan langsung mencetak Kartu Lanyard Khusus Non-Exclusive sebagai identitas tanda masuk resmi.
  • Sistem Cetak Kartu Fisik Lanyard/Badge Terintegrasi: Sistem berfokus pada otomatisasi pencetakan kartu/badge lanyard saat QR Code di-scan di pintu masuk. Kartu yang tercetak membedakan secara visual status pengunjung (Exclusive vs Non-Exclusive) melalui template desain yang dapat diunggah secara fleksibel oleh Admin.
  • Desain Premium Standar Taste-Skill & Tema Warna Tunggal (Monochromatic Palette): Tampilan antarmuka menggunakan satu tema warna utama yang konsisten (tidak ramai/warna-warni) dengan paduan aksen warna kontras menyala (vibrant high-contrast accents) serta elemen 3D profesional agar berkesan bersih, futuristik, berwibawa, dan responsif di semua perangkat.
  • Performa Kecepatan Tinggi & Kompresi Gambar Otomatis (Auto-Image Compress):
    • Pengunjung (kategori Exclusive) dapat memilih foto dari galeri atau langsung membuka kamera HP untuk mengambil foto bukti transfer.
    • Setiap gambar berukuran besar (seperti foto 10MB+) secara otomatis dikompresi di sisi browser pengguna menjadi < 500KB sebelum diunggah ke server untuk menjaga kecepatan web dan efisiensi ruang database.
  • Registrasi Onsite / Assistive Admin Registration: Form khusus di Dashboard Admin untuk membantu mendaftarkan pengunjung secara manual di lokasi acara (lansia / kendala perangkat) dengan opsi bayar tunai (Exclusive) atau registrasi instan (Non-Exclusive) dan pencetakan ID Card langsung di tempat.
  • Dynamic Pricing & Multi-Payment: Admin dapat merubah harga tiket Exclusive secara dinamis. Metode pembayaran mendukung QRIS (Domestik) dan Bank Transfer Luar Negeri IAGI (Internasional) yang dilengkapi kode unik 3 digit.
  • Flexibility Upload Design ID Card/Lanyard: Admin dapat mengunggah template desain ID Card/Lanyard fisik (Format PNG/JPG) secara terpisah untuk kategori Exclusive dan Non-Exclusive melalui Web Admin.

3. SPESIFIKASI TEKNIS (PRODUCT REQUIREMENT DOCUMENT)

3.1 Alur Pengguna (User Flow) & Mekanisme Kategori Tiket

  1. Registrasi Visitor Non-Exclusive (Gratis):
    • Pengunjung memilih kategori Non-Exclusive → Mengisi data diri (Nama, Email, No. HP/WhatsApp, Instansi).
    • Sistem tidak menagih pembayaran (Rp 0) → Langsung menerbitkan E-Tiket dengan QR Code Unik ke email dan halaman konfirmasi.
  2. Registrasi Visitor Exclusive (Berbayar):
    • Pengunjung memilih kategori Exclusive → Mengisi data diri & jumlah tiket/anggota.
    • Sistem mengkalkulasi nominal tiket + 3 digit kode unik → Pengunjung membayar via QRIS atau Transfer Bank Luar Negeri.
    • Pengunjung mengambil/memilih foto bukti transfer → Kompresi otomatis (< 500KB) → Unggah ke server.
    • Admin memverifikasi bukti bayar di Dashboard Admin → Sistem otomatis mengirimkan E-Tiket dengan QR Code Unik ke masing-masing email pengunjung.
  3. Alur Check-in di Pintu Masuk (Gate In) & Cetak Kartu Lanyard:
    • Pengunjung tiba di lokasi acara dan menunjukkan QR Code pada E-Tiket (baik Exclusive maupun Non-Exclusive).
    • Petugas pintu masuk melakukan pemindaian (scan) menggunakan Mobile Web Scanner Gate.
    • Sistem memvalidasi status tiket (Active / Already Checked-in / Invalid).
    • Jika valid, sistem mencatat status kehadiran (checked-in) dan memicu printer untuk mencetak Kartu Lanyard:
      • Jika kategori Exclusive: Mencetak ID Card dengan template desain Exclusive Badge.
      • Jika kategori Non-Exclusive: Mencetak ID Card dengan template desain Non-Exclusive Badge.
    • Petugas menyerahkan tali lanyard + kartu yang telah tercetak sebagai tanda pengenal resmi selama acara.
  4. Registrasi Onsite / Bantuan Admin di Lokasi:
    • Admin membuka menu Onsite Registration di Dashboard Admin → Mengisi data pengunjung.
    • Memilih kategori (Exclusive dengan bayar tunai / Non-Exclusive gratis) → Konfirmasi & langsung cetak kartu lanyard di meja registrasi onsite.

3.3 Rancangan Skema Database

CREATE TABLE settings (
    id INT AUTO_INCREMENT PRIMARY KEY,
    ticket_price_exclusive DECIMAL(12,2) DEFAULT 0.00,
    ticket_price_non_exclusive DECIMAL(12,2) DEFAULT 0.00, -- Default 0.00 (Gratis)
    exclusive_card_design_path VARCHAR(255) NULL,       -- Template Lanyard Exclusive
    non_exclusive_card_design_path VARCHAR(255) NULL,   -- Template Lanyard Non-Exclusive
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL
);

CREATE TABLE payments (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    payment_code VARCHAR(50) UNIQUE NOT NULL,
    payment_method ENUM('qris_indo', 'foreign_bank_transfer', 'cash_onsite') NOT NULL DEFAULT 'qris_indo',
    total_members INT NOT NULL DEFAULT 1,
    price_per_ticket DECIMAL(12, 2) NOT NULL,
    unique_code INT NOT NULL DEFAULT 0,
    total_amount DECIMAL(12, 2) NOT NULL,
    proof_of_payment VARCHAR(255) NULL,       -- Path file gambar dikompresi (< 500KB)
    original_file_size_kb INT NULL,           -- Ukuran sebelum kompresi
    compressed_file_size_kb INT NULL,         -- Ukuran setelah kompresi
    status ENUM('pending', 'approved', 'rejected') DEFAULT 'pending',
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL
);

CREATE TABLE tickets (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    payment_id BIGINT UNSIGNED NULL,          -- NULL jika Non-Exclusive (Gratis)
    registered_by_admin_id BIGINT UNSIGNED NULL, -- ID Admin jika registrasi Onsite
    registration_source ENUM('online_self', 'admin_onsite') DEFAULT 'online_self',
    visitor_name VARCHAR(150) NOT NULL,
    visitor_email VARCHAR(150) NOT NULL,
    visitor_phone VARCHAR(50) NULL,
    visitor_institution VARCHAR(150) NULL,
    ticket_code VARCHAR(100) UNIQUE NOT NULL,
    visitor_type ENUM('exclusive', 'non_exclusive') NOT NULL DEFAULT 'non_exclusive',
    is_group_leader BOOLEAN DEFAULT FALSE,
    status ENUM('pending', 'active', 'cancelled') DEFAULT 'active',
    checked_in BOOLEAN DEFAULT FALSE,
    checked_in_at TIMESTAMP NULL,
    card_printed BOOLEAN DEFAULT FALSE,       -- Flag pencetakan fisik kartu lanyard
    card_printed_at TIMESTAMP NULL,
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL,
    FOREIGN KEY (payment_id) REFERENCES payments(id) ON DELETE SET NULL
);
